🌐 Networking notes

Q: What port does SSH use by default?
A: 22

Q: What does DNS do?
A: Translates domain names into IP addresses

Q: Which layer of the OSI model does a router operate at?
A: Layer 3 (Network layer)

Q: Is UDP connection-oriented?
A: No

From the terminal

Q: Command to show IP addresses on Linux?
A: ip addr

Q: Command to test reachability of a host?
A: ping

Rapid fire

  1. Default HTTPS port — 443
  2. Protocol that assigns IP addresses automatically — DHCP
  3. Private IPv4 range starting with 192 — 192.168.0.0/16
  4. Loopback address — 127.0.0.1 / localhost
